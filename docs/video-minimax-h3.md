# MiniMax H3 接入（2026-10-28，本地待发布）

模型 ID 大小写必须是 `MiniMax-H3`，生成接口为 `/v1/videos/generations`，状态查询 `/v1/tasks/{task_id}`。工作区排在 Gemini Omni 之后，默认仍为 Seedance 2.5；H3 Max 不提前开放。

依据：[生成协议](https://docs.apimart.ai/en/api-reference/videos/minimax-h3/generation)、[模型价格表](https://apimart.ai/model/minimax-h3)。能力、价格核对日期为 2026-10-28；价格估算采用公开 Gold 档，结算使用任务实际 `cost` 美元值。

| 项目 | 本站实现与校验 |
| --- | --- |
| 文生视频 | 非空提示词，最多 7000 字符；整数 4–15 秒；768P 或 2K（默认 2K / 5 秒） |
| 画幅 | 21:9、16:9、4:3、1:1、3:4、9:16、自适应；纯文字自适应回落 16:9 |
| 首尾帧 | 图片卡片明确选择首帧或尾帧，各最多一张；发送独立字段，画幅自适应；与其他参考素材互斥；尾帧可单独使用 |
| 多模态参考 | 最多 9 图 / 3 视频 / 3 音频；所有普通图都走 `image_urls`，不根据数量猜首尾帧 |
| 图片 | JPG/JPEG/PNG/WebP/HEIC/HEIF，最多 30 MiB；宽高各 256–5760，比例 0.4–2.5 |
| 视频 | MP4/MOV，最多 50 MiB；H.264/AVC 或 H.265/HEVC，音轨 AAC/MP3；23.976–60 FPS；宽高各 256–5760，比例 0.4–2.5；每段 2–15 秒，总计最多 15 秒 |
| 音频 | MP3/PCM WAV，最多 15 MiB；每段 2–15 秒，总计最多 15 秒；必须搭配普通图片或视频 |
| 其他 | 原生有声，提供水印和可选内容预检查；预检查可能额外计费；不传 Seedance 的 seed、generate_audio、return_last_frame、tools 或审核素材 ID |

文件大小采用本站已有的 MiB 边界。素材通过私有 Storage 上传，服务端解析真实字节并签发带账户、型号与时效的收据；生成时再次校验，且在预留积分和向上游提交前拒绝不合规素材。HEIC/HEIF 用固定依赖 `pillow-heif==1.8.1` 校验，浏览器不能解码时显示说明，不伪造本地预览。视频通过有界 MP4 atom 解析取得真实尺寸、时长、帧率、音视频编码。参考素材 12 小时、提示词 7 天；生成链接不承诺固定保留时长，以返回期限为准，提醒及时下载。

## 积分

最终扣分：`ceil(实际美元费用 × 7 ÷ 0.38 × 1.2 × 2) ÷ 2`。只有明确实际费用才结算；`credits_cost` 存在时需与美元值 ×10 一致，不能直接把上游 Credits 当美元。缺费用保留 `awaiting_provider`，不把估价当实际费用。余额不足补差为 `awaiting_balance`，先补足再领取；重复查询不重复扣分。失败按原预留退回；提交结果未知只核对原任务。自带 Key 不扣网站积分。

预估 USD：`(生成秒数 + 参考视频秒数) × 分辨率单价 + max(参考图张数−5,0) × 0.02288`。768P 单价 0.05712 USD/秒，2K 单价 0.09144 USD/秒。音频不单独加时长；前 5 图免费，第 6–9 图按张。预留按估算 USD 的 1.6 倍再套扣分公式，页面分别显示预计消费与预留，最终退补仍以实际费用为准。

| 示例 | 预计 USD | 预计积分 | 提交预留 |
| --- | ---: | ---: | ---: |
| 768P / 5 秒 / 无参考 | 0.28560 | 6.5 | 10.5 |
| 2K / 5 秒 / 无参考 | 0.45720 | 10.5 | 16.5 |
| 768P / 5 秒 / 3 秒参考视频 + 9 图 | 0.54848 | 12.5 | 19.5 |
