# 积分兑换码与阿奇索卡库

2026-10-26：网站制码、兑换及 Omni 已正式部署；正式迁移分别为20261026131307_credit_code_redemption和20261026131305_omni_flash_actual_cost。用户确认已完成店铺配置，网站购买积分界面切换为淘宝选购与兑换，移除旧人工充值页及筹备提示。店铺与交流群二维码使用用户提供图片；实际发货/核销能力仍以商家配置为准，不把本网站标记兑换等同于淘宝核销。

下载文件名为“套餐名-本次导出未用码数量-批次说明.txt”，例如10元20积分-100-1.txt。数字说明里的“第/批”会去除；无说明使用批次UUID；路径及Windows非法字符会清理。部分码已用后只导出剩余码，文件名数量同步减少，下载重试不会重新制码。前端命名不修改库存或服务端兑换凭据。

本地4204中的卡密与积分均为隔离测试数据，不能导入正式卡库售卖；正式库存应从正式管理员控制台生成下载。

## 上线后怎样添加卡密

管理员控制台新增“积分兑换码”：选择套餐、填写数量与批次说明，生成后下载该批次 TXT。每批 1–500 个；首批可各生成 100 个，不提前把库存填成无限。

管理员制码不限制频率，可连续生成各档库存；按用户手动验收反馈已取消原10分钟10批限制。用户兑换限流、管理员身份校验及制码幂等仍保留。本地真实浏览器连续11批共110码通过，已有批次保留，制码不加积分。

进入对应阿奇索卡种的“添加卡密”，粘贴 TXT：**一行一个完整兑换码，不加序号、中文说明、逗号或价格**。用户截图中的导入说明允许单字段作为卡号，不必人为编造另一组密码；可以把卡号前缀改为“积分兑换码：”，密码前缀留空。切勿使用“重复卡密生成器”，不要把同一文件导入多个卡种。保持“唯一卡”，把淘宝各 SKU 关联到对应卡种。

用户购买后领取本站 PF 开头兑换码，在网站“购买积分→已有兑换码”登录并兑换，积分自动到账。淘宝的电子核销凭证与本站兑换码不是同一种数据；能导入卡库不代表淘宝已自动核销。

## 已实现的范围

- 服务端密码学随机数生成 128 位不可预测兑换码，28 位 Base32 字符，符合当前卡库输入长度。五种面额在数据库及服务端固定，客户端不能指定任意积分。
- 制码、下载不增加账户积分，也不作为已收款收入；兑换成功才新增 purchase 积分流水，关联批次、套餐与兑换码内部 ID。
- 兑换事务锁定批次、单码与账户，积分增加、流水、码状态、审计同事务提交。相同用户重试已用码返回原到账结果，其他用户无法再次使用。
- 服务端检查真实邮箱验证状态和账户状态；限流同时包含进程限制与数据库持久的每用户 10 分钟 12 次限制。无效输入也计次。
- 管理员批量制码、仅导出未用码、查看批次及近期兑换、单码作废、剩余批次作废。作废不扣回已到账积分，不替代淘宝退款。
- 用户只查看自己的最近 30 条兑换记录，管理员列表不显示完整兑换码；任何人持有码都可能兑换，应把下载文件当作有价库存保管。

## 仍需实际联调的部分

**本次没有开通阿奇索标准货源接口、淘宝订单授权、电子凭证自动核销、退款回调或无限自动补货。** 当前完成的是网站制码与自动兑换；阿奇索付款后自动发卡需由商家在其后台配置并用真实测试订单验证，网站没有接收到付款证明。

当前淘宝截图显示“购买后 7 天有效”，网站拿不到实际购买时间，故没有把“生成后 7 天”错误当作失效时间。正式销售前需确认电子凭证有效期、核销方式、售后规则与实际交付一致；不得宣称本站已自动执行淘宝凭证到期或核销。

退款时先核实淘宝订单及未用兑换码，再单码作废；批量作废只用于整批未售/撤销库存。已兑换的码只返回冲突，不自动撤销积分或更改生成任务。不要在保留有效码的同时直接退款。未售库存快用完时生成新批次补充，不复用旧码。

## 数据与密钥

新增公开表 credit_code_batches、credit_codes、credit_code_events 及私有限流表，全部启用 RLS，撤销 anon/authenticated/Public 访问；仅服务角色可执行 RPC。公开包装函数为 security invoker，私有受控函数固定空 search_path。管理员入口复用现有 require_admin_user，兼容 profiles.role 和服务端 ADMIN_USER_IDS；数据库管理员 RPC 只接受可信后端调用。

兑换凭据只保存 SHA256；完整批次额外用 Fernet 加密，以现有服务端 Supabase service/secret key 作目的分离派生，不新增前端密钥。**轮换该服务密钥会使旧批次无法再次解密导出，已发出码仍可凭哈希兑换**；轮换前妥善保管必要库存文件。码不写 URL、浏览器持久存储、普通历史、通用日志或流水明文；导出使用已鉴权请求和浏览器临时 Blob。

nominal_amount_fen 是套餐标价，不是核实后的淘宝实收；不能拿它直接记现金收入或把已制码库存算销售额。淘宝折扣、手续费、退款与实际回款需独立对账。
