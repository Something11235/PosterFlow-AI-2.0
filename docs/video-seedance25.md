## 能力与本站边界

| 能力 | 本地实现与限制 |
| --- | --- |
| 文字生成 | 4–30 秒或自动，480P / 720P / 1080P，七种画幅，种子含 0 |
| 多模态参考 | 最多 30 图、10 视频、10 音频，总计不超过 50；音频可单独参考 |
| 视频与音频时长 | 每段 2–30 秒，两类素材各自总计不超过 30 秒；视频 24–60 FPS、480P–1080P，检查实际编码与画面尺寸 |
| 首尾帧 | 已去掉图片用途总开关；图片默认普通参考，逐图指定首帧或尾帧；纯首尾帧要求自适应画幅，未指定帧角色时不锁画幅 |
| 首尾帧混合参考 | 混用视频或音频时上游将帧角色作为普通参考图，界面显式提醒，不能承诺固定开头/结尾 |
| 视频编辑 | 必须有 4–30 秒参考视频，自适应画幅、自动时长；提示词也须明确编辑意图 |
| 视频延长 | 必须有视频、自适应画幅；提示词明确延长，避免异步意图不匹配错误 |
| 样片与正式片 | 480P 样片；七天内本人已完成且已结算的样片可另付费生成 1080P 正式片；服务端从本人任务查源 ID，继承提示词/素材/声音/时长，不重发继承字段 |
| 高级参数 | 声音、尾帧返回、联网、内容检查、水印、MP4/MOV；请求白名单按模型验证 |
| 素材审核 | 可审核后复用，网站零积分，服务端保留归属与真实媒体元数据；自定义服务不假定支持审核路由 |

本站当前只开放 PNG/JPEG/WebP 图片（16 MiB）、MP4/MOV 视频（50 MiB）、MP3/PCM WAV 音频（15 MiB）。这些是网站限制，未把官方更多格式或 200 MB 视频上限误称本站已支持。上传/链接导入都检查真实字节、时长、尺寸、编码；私有参考素材十二小时清理，文字历史七天。生成视频直接使用返回地址，不转存原视频；2.5 文档和模型页对存储有效期表述不同，因此界面仅提示“有效期以返回结果为准，请及时下载备份”，不承诺永久保留。

首页视频卡片扩大，桌面/手机侧栏均显示“测试中”；保持移动布局与按钮可读。原音乐独立灵感行、提示词资源外链及 Mini 首尾帧说明继续保留。

追加统一创作编辑器：模型、提示词、上传/链接/审核素材、逐图角色、画幅、清晰度和时长在同一编辑区域；桌面采用整行布局，参考卡片滚动区有高度上限，避免大量素材把控件挤到页面很远处。画幅直接显示六种比例与自适应按钮，时长使用滑块和数字输入；2.5 范围 4–30 秒、可自动，Mini 范围 4–15 秒。编辑/延长、真实首尾帧、正式片继承等限制明确显示原因。

2.5 [官方模型参数表](https://apimart.ai/model/doubao-seedance-2-5) 明确支持 `@图片1`、`@视频1`、`@音频1`。输入 @ 或点击“引用素材”可选已校验素材，支持光标插入、方向键/Enter/Escape及中文输入法。各媒体按实际请求数组分别编号，所有添加素材均发送，@ 只指定用途。普通图片与帧角色混合时统一使用同一个有序 `image_with_roles` 数组，普通图补 `reference_image`，避免拆成两数组破坏图片编号。删除/异步导入后按素材身份同步更新已引用编号；被删除的引用留下明确标记并阻止误提交。Mini 文档未明确相同 @ 语法，暂不展示 @ 选择入口；仍可统一添加和逐图指定角色，非兼容组合阻止提交但保留素材。

## 定价、预留和结算

用户明确：网站积分最低售价为人民币 0.38 元，美元汇率按 7。新 2.5 的实际扣分为（后续新增视频模型暂用同一公式；Mini 维持固定秒价）：

`向上取整到 0.5 积分（实际扣费美元 × 7 ÷ 0.38 × 1.2）`

1.2 是用户明确指定的 20% 成本加价，另有最多不足 0.5 积分的向上取整。例如实际费用 USD 0.48，扣 11 网站积分。服务商 Credits 不等于网站积分；只使用任务完成返回的实际 USD `cost` 结算，可与 `credits_cost` 交叉校验，不将墙钟耗时 `actual_time` 当计费时长。

| 分辨率 | 无参考视频预估 USD/秒 | 有参考视频预估 USD/秒 |
| --- | --- | --- |
| 480P | 0.09608 | 0.0576 |
| 720P | 0.216 | 0.1296 |
| 1080P | 0.5346 | 0.3192 |

表为核对当时公开 Gold 档估算价，仅用于报价。带参考视频按参考视频加生成秒数估算，参考音频/图片不单独增加秒数；最终以实际账单为准。提交预留估算成本的 1.6 倍并向上取整到 0.5，覆盖画幅/token 带来的常见偏差，完成多退少补；自动时长按最多 30 秒预留。480P 五秒无视频参考预估 11、预留 17 积分。正式片为新任务单独计费，其估算不重复加入样片输入视频时长。

完成时费用可能晚于视频返回：保持待确认并轮询原任务，不先泄露结果或按零费用结算。超过预留且余额不足时保留真实账单、显示待补足，暂缓领取结果，并阻止新 2.5 平台任务，充值后刷新原任务结算。任务行保存定价版本和汇率快照，不因后来改价重算；预约、差额、退款都有幂等保护。此机制不承诺抵御任意幅度的未来上游涨价，发布时仍须复核价格。

自带 Key 不扣网站积分；仍需要登录验证归属，媒体存储规则相同。原 Mini 按用户先前指定的 480P 0.5 / 720P 1 积分每秒计费，图像、音乐和充值规则均未改变。

只读核对正式站 `/api/health`，`payment_enabled=false`。原在线充值后端还有“1 元换 10 积分”代码，但通道未启用；本轮不改充值业务。未来若启用该通道，必须先与最低 0.38 元/积分的定价前提对齐，否则本定价不能保证按实际售分价格盈利。

## 自带 Key 的接口地址

新增“视频生成接口地址”和可选“任务查询地址模板”，点击“应用视频服务配置”后生效；Key、地址只在当前页面内存中，刷新/切换账户清空。自带 Key 模式界面两地址均默认空白，没有真实网站示例，生成地址必须用户填写；符合标准结尾的生成地址可推导同源 `/v1/tasks/{task_id}`，其他兼容服务须填写模板。平台服务仍使用固定服务端地址，不受自定义框影响。

生成、查询确实使用选定地址，要求兼容当前视频请求/异步任务协议，不承诺任意服务。只允许公网 HTTPS、同源地址，不允许用户信息、查询参数、重定向或私网解析；自定义请求采用 DNS 固定与 TLS/SNI 校验。Key 与两地址共同隔离任务归属。平台积分模式完全忽略自定义地址，平台服务器 Key 不会转发至用户地址。标准旧自带 Key 归属哈希保持兼容。
