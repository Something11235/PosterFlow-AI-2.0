# 新版创作工作台：本地预览

2026-10-21。按用户最新要求，仅包含图像、视频、音乐；不提供独立音频生成、配音或转写。

## 打开界面

在项目根目录执行：

```powershell
npm run build --prefix frontend
npm run preview:studio --prefix frontend
```

打开 http://127.0.0.1:4174 。旧界面可以通过 http://127.0.0.1:4174/?workspace=classic 对照查看。预览仅监听本机，关闭服务使用 Ctrl+C；默认端口被占用时可通过 `STUDIO_PREVIEW_PORT` 环境变量指定其他端口。

这个独立预览服务只读取 `frontend/dist`，不读取 `.env`，不代理业务接口。它返回明确的预览健康状态，其他业务操作返回503；CSP限制页面只能连接本机，阻止外部认证与生成调用。因此本预览可以审阅布局和本地草稿，不能登录真实账号、读取线上历史或调用真实图像服务。正常前后端开发环境继续使用原来的图片服务和账号接口。

## 已实现的界面与交互

- 深石墨色与薄荷绿的创作导航、首页、三类创作入口；本地绘制的概念插图标明“示意设计”。
- 图像：复用既有编辑器、重绘、画廊和无限画布，保留提示词、参考图和画布挂载；历史复用会切回图像编辑器。
- 视频：首批 Seedance 1.5 Pro、Veo 3.1 Fast、Wan 2.6。切换模型自动校正不兼容的时长、分辨率和比例；只为支持的模型发送音轨参数。
- 音乐：Suno v6 的灵感与自定义歌词、标题/风格、纯音乐；切换两种模式时分别保留文本，避免把描述误作歌词。
- 模型一览：按图像/视频/音乐筛选、搜索、查看官方文档；目录是候选能力，不代表账号已获模型权限。
- 创作草稿：校验、保存、查看参数、编辑、删除与JSON导出。最多30份，仅在本次页面会话的内存中保存；刷新、关闭或切换登录身份会清空。不会写数据库、localStorage或七天提示词历史。

视频与音乐生成服务尚未接入。保存草稿不提交上游任务、不预扣积分，也不会展示模拟成功作品或伪造进度。新媒体后端、任务恢复、结算、存储和迁移仍是方案，见 [升级方案](./multimedia-upgrade-plan.md)。

## 文件边界

- `frontend/src/App.jsx`：保留业务状态与弹窗，新增独立工作区选择；非图像页的 Ctrl/Command+Enter 不触发原图像生成。
- `frontend/src/components/studio/`：导航、工作区、概念插图、局部样式。
- `frontend/src/lib/studioCatalog.js`：核实的候选参数、模型切换与草稿字段白名单。没有网络调用、定价或Key存储。
- `scripts/preview-studio.mjs`：只读、本机、无业务代理的界面预览。
- 没有后端业务、数据库迁移、依赖、生产环境变量或线上配置变更；增加一个本地预览npm脚本。
