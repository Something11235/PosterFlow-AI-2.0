## 文档依据与计费口径

- [视频生成](https://docs.apimart.ai/cn/api-reference/videos/seedance-2-0/generation)：`POST /v1/videos/generations`，模型精确为 `seedance-2.0-mini`，返回 `data[0].task_id`。
- [Mini 官方模型与价格页](https://apimart.ai/model/doubao-seedance-2-0-mini)：480P / 720P，4–15 秒；FAQ 将无参考视频的计费时长定义为生成时长，有参考视频则为参考视频＋生成时长，没有为参考音频另列时长。因此本站不加参考音频、图片时长。此为现行公开规则的实现，尚未用实际收费订单核账。
- [统一任务查询](https://docs.apimart.ai/cn/api-reference/tasks/status)：`GET /v1/tasks/{id}?language=zh`，生成视频从 `data.result.videos[].url[]` 读取。
- [虚拟人像素材](https://docs.apimart.ai/cn/api-reference/videos/seedance-2-0/private-avatar)：返回 `data.id`，查询后使用 `usable_assets` / `assets` 中 Active 的 `asset://` 地址；单素材兼容 `result.asset_url`。

用户指定的网站定价：480P 每秒 0.5 积分，720P 每秒 1 积分。以服务端校验的参考视频总毫秒数，加本次选定生成秒数计算。5 秒视频＋3 秒音频＋10 秒生成的 480P 任务为 7.5 积分；只有图片和音频、生成 10 秒则 5 积分。服务商的 Credits 价格表不是网站积分；`actual_time` 是处理耗时，绝不能用来扣分。

## 已实现的入口

视频工作区支持文字、最多 9 张图片、3 段视频、3 段音频的多模态创作，或首尾帧各一张图片；首尾帧禁止混用视频、音频。人像参考角色需要本人审核通过的素材。所有已添加素材都会参与请求，不以提示词是否含 `@` 决定是否发送。

首尾帧图片按空位默认分配：第一张首帧、第二张尾帧，每张卡片展示开始/结束徽标和角色下拉；手动修改时对调另一张，确保两张不会意外同为首帧。角色通过 `image_with_roles[].role` 明确发送，上传顺序不代替角色参数。图片用途旁说明普通多模态参考、控制开头结尾、审核人像特征参考三种用途。

控制项包含 4–15 秒、480P / 720P、7 种画幅（含 adaptive）、可选种子（0 保留）、声音、返回尾帧、联网搜索和内容预检查。Mini 不展示 1080P / 4K。预检查只覆盖提示词与图片，服务不可用时可能继续请求，最终以生成审核为准。其他视频候选模型保持预览，不能静默转换为 Mini。

本站文件限制：PNG/JPEG/WebP 16 MiB、MP4/MOV 50 MiB、MP3/PCM WAV 20 MiB；提示词上限 32000 字符、种子 -1 至 2147483647，都是网站限制，不冒充官方硬上限。视频仅接单视频轨的 ISO-BMFF 容器，读取容器与视频轨时长的较大值，校验 480P–720P；总参考视频时长 >1.8 秒且 <15.2 秒，音频总时长 ≤15 秒且必须搭配图片/视频。读取真实字节和媒体头，不信任浏览器填写的时长，不运行上传文件或调用 shell 解码器。

素材可从本地直传，或经固定公共 IP / TLS 校验传输导入 HTTPS 链接。服务端校验后签发所有者 HMAC 凭证；上传与已校验凭证分阶段，不能跨账户、跨 Key 或混用音乐素材票据。请求前再次检查有效期；旧凭证仅用于匹配已有请求，不能发起新生成。

每次网站素材审核只处理一份文件，避免官方批量响应未承诺顺序造成错误绑定。页面可以多次审核并复用已有素材；不是上游批量 20 份素材的代理。审核不扣网站积分，不承诺服务商审核也免费。只允许使用该账户和当前计费/Key 范围内已保存的审核素材，不能输入其他用户的任意 asset ID。平台服务使用新变量 `APIMART_VIDEO_API_KEY`；不回退复用图像或音乐 Key。自带 Key 只放页面内存，需登录并验证邮箱。

## 任务、存储与账目

`video_jobs` 独立保存任务元数据和七天文字历史，不保存媒体 URL、上传凭证或 Key；素材审核结果只保存 asset ID 和已验证来源元数据。图片/音乐原表、模型价格与请求协议保留。上传文件使用原私有 bucket 下严格独立的 `posterflow/video-<owner hash>/references/` 前缀；12h 清理通过 Storage API 执行，复用原 Vault 配置，新 Cron 在每小时 47 分执行，不碰原图片和音乐清理。临时媒体实际删除可能晚于过期边界一个调度周期，票据按 12h 到期立即不可再用。

生成视频使用服务商临时地址直接预览和保存，不复制到 Supabase；官方页面标注约 72h 有效，任务仍可查询不等于媒体永久有效。播放器 `preload=none`，点击后才加载视频；保留下载、备用下载和失败提示。请求尾帧后，若结果含已识别尾帧 URL，可下载或导入为下一段首帧。官方未固定尾帧结果字段名，当前兼容已知名称；该字段真实返回形状、实际音画质量和账户权限仍待收费联调确认，不能把模拟返回当成实测。

平台每人最多 3 个非终态视频任务，素材审核另外最多 3 个。先原子预留，成功结算一次，明确失败退回一次；超时、5xx 或不完整提交响应标为结果未知，保留预留积分，不自动重发。刷新只查询原任务；提交成功但保存任务号失败也不能擅自退款或重发。查询失败不是生成失败。创建意图由账户行锁与请求编号事务锁串行化，同请求号不同参数返回冲突。

共享账户及流水升级为 `numeric(18,4)`；浏览器报价用万分之一积分整数单位运算，后端 Decimal 验证，数据库独立计算费率和总额，不能由客户端传单价。仅改原积分函数的余额局部变量/余额取值类型，不改变原图像、音乐和充值价格；新增独立名称的管理员小数调整 RPC，避免整型/数值型重载造成调用歧义。管理员视频用量、实际积分与全站 DAU 同步：当天建立过图像、音乐或视频生成任务的账号去重计数，素材上传/审核不计入。
