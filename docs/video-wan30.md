## 能力与约束

| 项目 | 本站实现 |
| --- | --- |
| 文字 / 多模态 | 文字或至少一份素材即可；最多 20000 字符（本站不静默截断）；允许单独参考音频和空提示词 |
| 时长 | 整数 2–30 秒或自动 `-1`；参考视频总时长＋输出时长≤30秒 |
| 输出 | 480P / 720P / 1080P，显式默认 1080P / 5秒；自适应、16:9、4:3、1:1、3:4、9:16，无21:9 |
| 首尾帧 | 首帧必选，尾帧可选，各最多一张；不能混用普通参考图、音视频、文档或网页 |
| 普通参考图 | 最多10张；显式 `image_with_roles: reference_image`，防止单张图被接口猜成首帧 |
| 图片格式 | JPEG/JPG/PNG（无透明通道）/BMP/WebP；20 MiB；宽高240–8000，长短边比≤8:1；不沿用 H3 HEIC 规则 |
| 视频 | 最多5段MP4/MOV；100 MiB；宽高240–4096，长短边比≤8:1；每段1–15秒，总计≤15秒；文档没规定H3的FPS/编码额外限制，因此不照搬 |
| 音频 | 最多5段MP3/PCM WAV；15 MiB；每段1–15秒，总计≤15秒；与视频分别计算总时长 |
| 文档 | 最多1份，100 MiB/50页；docx/doc/xlsx/xls/pptx/ppt/pdf/txt/key/pages/numbers/md；可上传或安全链接导入 |
| 网页 | 可填一个公开、无需登录的HTTPS网页；与文档、首尾帧互斥，可与普通参考素材搭配 |
| 其他 | 原生声音开关 `audio`（默认true）、seed=0–2147483647、水印、可选内容预检查；不发送旧型号generate_audio、尾帧导出、tools等字段 |

仍使用统一素材区，用户直接给图片指定首帧/尾帧，文档和网页无需额外模式切换。提示词支持引用素材菜单；本站的 `@图片N / @视频N / @音频N` 在发送时转为文档认可的 `图N / 视频N / 音频N`，各类型保持上传顺序；移除素材会重新映射并提示失效引用。

## 素材校验与历史

上传仍走私有 Storage、带账户/服务范围/型号/时效的签名收据，先校验真实内容再允许生成。PNG带alpha通道、尺寸不合规、过短或超总时长、首尾帧混用、缺少首帧、文档网页并用均在预留前拒绝。切换模型复用旧收据时会重新读取原字节、核对SHA256，并应用Wan校验，避免旧收据未记录透明通道时漏检。没有把桶改成公开。

文档新增固定依赖 `pypdf==6.21.3`：PDF读取真实页数，PPTX计幻灯片，DOCX检查可用的Pages元数据；Office/iWork仅有界读取ZIP目录/小元数据，旧Office检查OLE容器，TXT/Markdown检查可读编码。拒绝加密PDF、未知/伪装格式、超限页数和超出本站解压边界的压缩文件，不运行宏、外部转换进程或网页脚本。某些Office/iWork格式不能可靠提前确定排版页数，界面明确最终页数以服务解析为准，不能宣称所有格式已在本地精确分页。

网页链接只交给生成服务，不由本站充当网页代理；拒绝非HTTPS、带账号密码、localhost/内网字面地址等。网页地址不保存到提示词历史；文档签名地址也不进入历史参数。历史只保留文字与安全设置，需要重新添加原素材。参考素材12小时、提示词7天；视频链接按返回结果提供，提醒及时下载，不承诺永久保存。

## 计费
